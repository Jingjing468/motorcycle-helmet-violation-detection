# Prediction outputs

The existing real annotated prediction images are kept in `results/figures/examples/` to preserve their established paths and side-by-side comparisons. They include:

- `single_rider_result.jpg`
- `crowded_traffic_result.jpg`

The input images and comparison layouts are alongside those files. These are examples from individual application runs, not a complete benchmark set. New prediction outputs can be saved here when they are generated from the real model and clearly associated with their input.
