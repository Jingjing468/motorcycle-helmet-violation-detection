# Dataset

The project notes identify a Roboflow Version 4 dataset with approximately 8,481 images. The four documented classes are `bike`, `helmet`, `no-helmet`, and `number-plate`. Exact Version 4 train, validation, and test split counts are not documented here.

The ignored local dataset directory contains Version 3 metadata (`data.yaml`) and uses the same four class names. Dataset copies are excluded from Git. The README describes reported local Version 3 counts; consult that local export metadata before reusing those numbers. The source export records CC BY 4.0; follow the dataset's attribution terms when redistributing it.
